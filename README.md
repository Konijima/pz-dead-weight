# Weight Scale

A small Project Zomboid mod: stand on a working medical scale and your body
weight appears near the top right of screen centre, then leaves when you
step off. No context menu, no timed action, no window.

Originally a Build 41 mod (Steam Workshop item `2833096579`) with a
context-menu action and a nutrition-values window. Reworked from the
approved v2 maquette (`docs/maquettes/hud-poids-v2.html`) into a weight-only
HUD, drawn entirely with textures, a rotated texture and rectangles, no
`drawText`, so the player's font-size option cannot change the look.

**Status: HUD rework implemented from a single source under `src/`, synced
into both live trees, old window/context-menu code removed.** Bench passes
(`tests/run.sh`): mapX contact points, band inclusivity, one-decimal format,
prefs parser robustness, and a JS/Lua parity check against the maquette's own
`anim.js` sampler. See `docs/API-COMPAT.md` for every game API call and its
B41/B42 evidence, and `docs/TEST-EN-JEU.md` for the in-game checklist still
to run (this machine has no B41 install to verify against).

## Layout

The repository root is the mod folder itself, laid out so both builds can
load from the same copy. **`media/`, `42/media/` and `common/media/textures`
are generated by `tools/sync.sh` from `src/`: never hand edit them.**

- `src/lua/client/WeightScale/` -- the single source for the Lua modules.
  `src/textures/` -- the single source for the HUD's textures.
- Root `mod.info`, `poster.png` and `media/` -- the Build 41 side. Build 41
  reads these straight from the mod folder root.
- `42/` -- the Build 42 mod folder: `mod.info`, `poster.png`, and
  `media/lua/client/WeightScale` synced from `src/`. This is what Build 42
  loads once the mod is enabled.
- `common/` -- shared media (models, scripts, sound, textures); textures are
  synced from `src/textures/`.
- The original downloaded 2022 B41 release is not kept in the tree any more:
  it lives in git history at commit `6631165`, and on the Steam Workshop.
- `docs/` -- `maquettes/hud-poids-v2.html` (the approved contract) plus
  `API-COMPAT.md` and `TEST-EN-JEU.md` for this rework.
- `workshop/` -- Steam Workshop material: `workshop.txt` (item id
  `2833096579` and the original description) and the original poster image.
- `tools/` -- `sync.sh` (src -> live trees), `check-sync.sh` (drift check),
  `gen-geo.py` (geometry.json -> WeightScaleGeo.lua).
- `tests/` -- `run.sh`, the pure-Lua bench and the JS/Lua parity check.

## Install (from source)

Clone or copy the repository so `42/` becomes the mod folder Project Zomboid
loads, e.g. symlink or copy `42/` to `~/Zomboid/mods/WeightScale` once the
rework is ready to run (a symlinked mod folder does not reliably load its
scripts in Build 42, so use a real copy).

## Mod id

`mod.info` keeps the original id `WeightScale` so existing Workshop
subscribers are not orphaned by the rework.
